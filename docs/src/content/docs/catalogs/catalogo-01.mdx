Catálogo SUNAT que identifica el tipo de comprobante de pago electrónico generado por el emisor. Es uno de los valores más importantes de la firma XML y del nombre del archivo ZIP enviado a SUNAT.

## Tabla de códigos

| Código | Descripción |
|--------|-------------|
| 01 | Factura |
| 03 | Boleta |
| 07 | Nota de Crédito |
| 08 | Nota de Débito |
| 09 | Guía de Remisión |
| 20 | Comprobante de Retención |
| 40 | Comprobante de Percepción |

## Uso típico

Se utiliza en los campos `tipoComprobante` de los modelos:

- `Invoice` y `CreditNote` / `DebitNote` (implícito por el modelo).
- `VoidedDocumentsItem.tipoComprobante` para comunicaciones de baja.
- `SummaryDocuments` → `Comprobante.tipoComprobante` en resúmenes diarios.
- `PercepcionRetencionOperacion.comprobante.tipoComprobante` en percepciones y retenciones.

También forma parte del nombre del archivo ZIP:

```text
{RUC}-{TIPO}-{SERIE}-{NUMERO}.zip
```
