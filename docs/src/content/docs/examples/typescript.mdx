title: Ejemplo en TypeScript
description: Crea una factura, obtén el XML y fírmala usando el SDK TypeScript de openUBL.
---

Este ejemplo usa el SDK `@openubl/sdk` con validación runtime mediante los schemas Zod generados desde OpenAPI.

## Crear y firmar una factura

```typescript
import { client, zInvoice, zSignXmlApiV1SignPostBody } from "@openubl/sdk";

const invoice = zInvoice.parse({
  serie: "F001",
  numero: 1,
  proveedor: {
    ruc: "20100111111",
    razonSocial: "Mi Empresa S.A.C.",
  },
  cliente: {
    nombre: "Juan Perez",
    numeroDocumentoIdentidad: "12345678",
    tipoDocumentoIdentidad: "1",
  },
  detalles: [
    {
      descripcion: "Producto A",
      cantidad: 2,
      precio: 100.0,
    },
  ],
  moneda: "PEN",
});

async function createAndSign() {
  // 1. Crear el XML
  const { data: createData, error: createError } = await client.post(
    "/api/v1/invoice/create",
    {
      body: invoice,
    },
  );

  if (createError) {
    throw new Error(`Error al crear factura: ${JSON.stringify(createError)}`);
  }

  const xml = createData.xml;
  console.log("XML generado:\n", xml);

  // 2. Firmar el XML
  const certPem = process.env.CERT_PEM ?? "";
  const keyPem = process.env.KEY_PEM ?? "";

  const body = zSignXmlApiV1SignPostBody.parse({
    xml,
    cert_pem: certPem,
    key_pem: keyPem,
  });

  const { data: signData, error: signError } = await client.post("/api/v1/sign", {
    body,
  });

  if (signError) {
    throw new Error(`Error al firmar: ${JSON.stringify(signError)}`);
  }

  console.log("XML firmado:\n", signData.signed_xml);
}

createAndSign();
```

## Variantes rápidas

### Nota de crédito

```typescript
import { client, zCreditNote } from "@openubl/sdk";

const creditNote = zCreditNote.parse({
  serie: "BC01",
  numero: 1,
  comprobanteAfectadoSerieNumero: "F001-1",
  sustentoDescripcion: "Anulación de venta",
  proveedor: invoice.proveedor,
  cliente: invoice.cliente,
  detalles: invoice.detalles,
  moneda: "PEN",
});

const { data, error } = await client.post("/api/v1/credit-note/create", {
  body: creditNote,
});

if (error) throw error;
console.log(data.xml);
```

### Comunicación de baja

```typescript
import { client, zVoidedDocuments } from "@openubl/sdk";

const voided = zVoidedDocuments.parse({
  numero: 1,
  fechaEmisionComprobantes: "2024-01-15",
  proveedor: invoice.proveedor,
  comprobantes: [
    {
      serie: "F001",
      numero: 1,
      tipoComprobante: "01",
      descripcionSustento: "Error en datos del cliente",
    },
  ],
});

const { data, error } = await client.post("/api/v1/voided-documents/create", {
  body: voided,
});

if (error) throw error;
console.log(data.xml);
```

## Con `fetch` nativo

Si prefieres no usar el SDK, puedes llamar a la API directamente con `fetch`:

```typescript
const BASE_URL = "http://localhost:8000";

const createRes = await fetch(`${BASE_URL}/api/v1/invoice/create`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(invoice),
});

if (!createRes.ok) {
  throw new Error(`Error: ${await createRes.text()}`);
}

const { xml } = (await createRes.json()) as { xml: string };
```
