description: Crea una factura, obtén el XML y fírmalo usando TypeScript y fetch.
---

Este ejemplo usa `fetch` nativo (disponible en Node.js 18+, Deno y Bun). Si prefieres tipos estáticos, puedes usar el [SDK de TypeScript](/sdk/typescript) basado en `openapi-fetch`.

## Crear y firmar una factura

```typescript
const BASE_URL = "http://localhost:8000";

// 1. Definir la factura
const invoice = {
  serie: "F001",
  numero: 1,
  proveedor: {
    ruc: "20100111111",
    razonSocial: "Mi Empresa S.A.C.",
  },
  cliente: {
    nombre: "Juan Perez",
    numeroDocumentoIdentidad: "12345678",
    tipoDocumentoIdentidad: "1",
  },
  detalles: [
    {
      descripcion: "Producto A",
      cantidad: 2,
      precio: 100.0,
    },
  ],
  moneda: "PEN",
};

async function createAndSign() {
  // 2. Crear el XML
  const createRes = await fetch(`${BASE_URL}/api/v1/invoice/create`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(invoice),
  });

  if (!createRes.ok) {
    const err = await createRes.json();
    throw new Error(`Error al crear factura: ${JSON.stringify(err)}`);
  }

  const { xml } = (await createRes.json()) as { xml: string };
  console.log("XML generado:\n", xml);

  // 3. Firmar el XML
  const certPem = process.env.CERT_PEM ?? "";
  const keyPem = process.env.KEY_PEM ?? "";

  const signRes = await fetch(`${BASE_URL}/api/v1/sign`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      xml,
      cert_pem: certPem,
      key_pem: keyPem,
      signature_id: "SignSUNAT",
    }),
  });

  if (!signRes.ok) {
    const err = await signRes.json();
    throw new Error(`Error al firmar: ${JSON.stringify(err)}`);
  }

  const { signed_xml } = (await signRes.json()) as { signed_xml: string };
  console.log("XML firmado:\n", signed_xml);
}

createAndSign();
```

## Con el SDK tipado

Si generaste los tipos con `openapi-typescript`, el cliente te ofrece autocompletado de endpoints y validación en tiempo de compilación:

```typescript
import createClient from "openapi-fetch";
import type { paths } from "./openubl-types";

const client = createClient<paths>({ baseUrl: BASE_URL });

const { data, error } = await client.POST("/api/v1/invoice/create", {
  body: invoice,
});

if (error) throw error;
console.log(data.xml);
```

## Variantes rápidas

### Nota de crédito

Reemplaza el endpoint y el payload:

```typescript
const creditNote = {
  serie: "BC01",
  numero: 1,
  comprobanteAfectadoSerieNumero: "F001-1",
  sustentoDescripcion: "Anulación de venta",
  proveedor: invoice.proveedor,
  cliente: invoice.cliente,
  detalles: invoice.detalles,
  moneda: "PEN",
};

await fetch(`${BASE_URL}/api/v1/credit-note/create`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(creditNote),
});
```

### Comunicación de baja

```typescript
const voided = {
  numero: 1,
  fechaEmisionComprobantes: "2024-01-15",
  proveedor: invoice.proveedor,
  comprobantes: [
    {
      serie: "F001",
      numero: 1,
      tipoComprobante: "01",
      descripcionSustento: "Error en datos del cliente",
    },
  ],
};

await fetch(`${BASE_URL}/api/v1/voided-documents/create`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(voided),
});
```
