---
title: C# SDK
description: Generación y uso del SDK de C# para openUBL con openapi-generator-cli.
---

El SDK de C# se genera a partir de `openapi.json` mediante `openapi-generator-cli`. El resultado es una biblioteca .NET con modelos y un cliente `RestSharp` o `HttpClient` según la configuración por defecto del generador.

## Generar el SDK

```bash
npx @openapitools/openapi-generator-cli generate \
  -i openapi.json \
  -g csharp \
  -o sdk/csharp
```

El código generado se encuentra en `sdk/csharp/` y puede compilarse con `dotnet build` o incluirse como proyecto de referencia.

## Alternativa con Docker

```bash
docker run --rm -v ${PWD}:/local openapitools/openapi-generator-cli generate \
  -i /local/openapi.json \
  -g csharp \
  -o /local/sdk/csharp
```

## Uso

El generador expone cada modelo como una clase con propiedades públicas. El siguiente ejemplo crea una factura y la envía mediante el cliente generado:

```csharp
using Openubl.Client;
using Openubl.Model;

var config = new Configuration
{
    BasePath = "http://localhost:8000"
};

var client = new ApiClient(config);
var api = new InvoiceApi(client);

var invoice = new Invoice(
    serie: "F001",
    numero: 1,
    proveedor: new Proveedor(
        ruc: "20100066603",
        razonSocial: "Softgreen S.A.C."
    ),
    cliente: new Cliente(
        nombre: "Carlos",
        numeroDocumentoIdentidad: "12121212121",
        tipoDocumentoIdentidad: "6"
    ),
    detalles: new List<DocumentoVentaDetalle>
    {
        new DocumentoVentaDetalle(
            descripcion: "Item",
            cantidad: 10,
            precio: 100
        )
    }
);

try
{
    var response = api.ApiV1InvoiceCreatePost(invoice);
    Console.WriteLine(response.Xml);
}
catch (ApiException ex)
{
    Console.WriteLine($"Error {ex.ErrorCode}: {ex.Message}");
}
```

:::note
El espacio de nombres (`Openubl`) y los nombres de métodos pueden variar ligeramente según la versión del generador y las etiquetas de operación definidas en `openapi.json`. Consulta `sdk/csharp/src/Openubl/` para verificar los identificadores exactos.
:::
