El SDK de Go se genera a partir de `openapi.json` mediante `openapi-generator-cli`, produciendo paquetes tipados y un cliente basado en `net/http`.

## Generar el SDK

```bash
npx @openapitools/openapi-generator-cli generate \
  -i openapi.json \
  -g go \
  -o sdk/go
```

El código generado queda disponible en `sdk/go/` y puede incorporarse a tu proyecto con `go mod` o copiando los paquetes directamente.

## Alternativa con Docker

```bash
docker run --rm -v ${PWD}:/local openapitools/openapi-generator-cli generate \
  -i /local/openapi.json \
  -g go \
  -o /local/sdk/go
```

## Uso

El generador crea un paquete principal que contiene las estructuras y el cliente. El siguiente ejemplo crea una factura y la envía al endpoint correspondiente:

```go
package main

import (
	"context"
	"fmt"
	"log"

	openubl "github.com/openubl/sdk/go"
)

func main() {
	config := openubl.NewConfiguration()
	config.Host = "localhost:8000"
	config.Scheme = "http"

	client := openubl.NewAPIClient(config)

	invoice := openubl.Invoice{
		Serie:  openubl.PtrString("F001"),
		Numero: openubl.PtrInt32(1),
		Proveedor: &openubl.Proveedor{
			Ruc:           openubl.PtrString("20100066603"),
			RazonSocial:   openubl.PtrString("Softgreen S.A.C."),
		},
		Cliente: &openubl.Cliente{
			Nombre:                  openubl.PtrString("Carlos"),
			NumeroDocumentoIdentidad: openubl.PtrString("12121212121"),
			TipoDocumentoIdentidad:  openubl.PtrString("6"),
		},
		Detalles: []openubl.DocumentoVentaDetalle{
			{
				Descripcion: openubl.PtrString("Item"),
				Cantidad:    openubl.PtrInt32(10),
				Precio:      openubl.PtrFloat64(100),
			},
		},
	}

	resp, r, err := client.InvoiceAPI.ApiV1InvoiceCreatePost(context.Background()).Invoice(invoice).Execute()
	if err != nil {
		log.Fatalf("Error: %v (HTTP %d)", err, r.StatusCode)
	}

	fmt.Println(resp.GetXml())
}
```

## Firma digital

El cliente generado puede firmar el XML llamando al endpoint `/api/v1/sign` con PEM o con PFX/P12.

### Firma con PEM

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	openubl "github.com/openubl/sdk/go"
)

func main() {
	certPem, err := os.ReadFile("certificado.pem")
	if err != nil {
		log.Fatal(err)
	}
	keyPem, err := os.ReadFile("llave_privada.pem")
	if err != nil {
		log.Fatal(err)
	}

	config := openubl.NewConfiguration()
	config.Host = "localhost:8000"
	config.Scheme = "http"

	client := openubl.NewAPIClient(config)
	body := map[string]interface{}{
		"xml":       xml,
		"cert_pem":  string(certPem),
		"key_pem":   string(keyPem),
	}

	signResp, r, err := client.SignAPI.ApiV1SignPost(context.Background()).Body(body).Execute()
	if err != nil {
		log.Fatalf("Error: %v (HTTP %d)", err, r.StatusCode)
	}

	fmt.Println(signResp.GetSignedXml())
}
```

### Firma con PFX/P12

```go
package main

import (
	"context"
	"encoding/base64"
	"fmt"
	"log"
	"os"

	openubl "github.com/openubl/sdk/go"
)

func main() {
	pfxBytes, err := os.ReadFile("certificado.pfx")
	if err != nil {
		log.Fatal(err)
	}
	pfxBase64 := base64.StdEncoding.EncodeToString(pfxBytes)

	config := openubl.NewConfiguration()
	config.Host = "localhost:8000"
	config.Scheme = "http"

	client := openubl.NewAPIClient(config)
	body := map[string]interface{}{
		"xml":           xml,
		"pfx_base64":    pfxBase64,
		"pfx_password":  "mi_clave",
	}

	signResp, r, err := client.SignAPI.ApiV1SignPost(context.Background()).Body(body).Execute()
	if err != nil {
		log.Fatalf("Error: %v (HTTP %d)", err, r.StatusCode)
	}

	fmt.Println(signResp.GetSignedXml())
}
```

:::note
El generador de Go utiliza punteros para campos opcionales y expone helpers como `PtrString` o `PtrInt32`. Los nombres exactos de los métodos del cliente dependen de las etiquetas de operación en `openapi.json`; verifica `sdk/go/api_*.go` para confirmar.
:::
