openUBL ofrece dos alternativas para trabajar con Python. La forma recomendada es utilizar la biblioteca nativa (`openubl`), que incluye modelos Pydantic, renderizado de XML, firma digital y validación SUNAT integrada.

## Opción A: biblioteca nativa (oficial)

Instala el paquete desde PyPI:

```bash
pip install openubl
```

Importa los modelos Pydantic definidos en `openubl.models`:

```python
from openubl.models import Invoice, Proveedor, Cliente, DocumentoVentaDetalle

invoice = Invoice(
    serie="F001",
    numero=1,
    proveedor=Proveedor(
        ruc="20100066603",
        razonSocial="Softgreen S.A.C.",
    ),
    cliente=Cliente(
        nombre="Carlos",
        numeroDocumentoIdentidad="12121212121",
        tipoDocumentoIdentidad="6",
    ),
    detalles=[
        DocumentoVentaDetalle(
            descripcion="Item",
            cantidad=10,
            precio=100,
        )
    ],
)

xml_output = invoice.to_xml()
print(xml_output)
```

### Firma digital

La biblioteca nativa expone `sign_ubl_xml` para firmar el XML directamente en el proceso, sin depender del servicio REST.

#### Firma con PEM

```python
from openubl.signer import sign_ubl_xml

with open("certificado.pem", "r") as f:
    cert_pem = f.read()

with open("llave_privada.pem", "r") as f:
    key_pem = f.read()

signed_xml = sign_ubl_xml(
    xml_output,
    cert_pem=cert_pem,
    key_pem=key_pem,
    signature_id="SignSUNAT",
)
print(signed_xml)
```

#### Firma con PFX/P12

```python
from openubl.signer import load_pfx, sign_ubl_xml

with open("certificado.pfx", "rb") as f:
    pfx_bytes = f.read()

key_pem, cert_pem = load_pfx(pfx_bytes, password="mi_clave")
signed_xml = sign_ubl_xml(xml_output, cert_pem, key_pem)
print(signed_xml)
```

Puedes consultar la versión instalada rápidamente:

```python
import openubl
print(openubl.__version__)
```

### Validación de versión

El módulo `openubl.version` expone `check_api_version` para verificar en runtime que la versión de la API coincide con la del SDK:

```python
from openubl.version import check_api_version

result = check_api_version("http://localhost:8000")
assert result["ok"], f"Desfase de versión: SDK {result['sdk_version']} vs API {result['api_version']}"
```

## Opción B: generar un cliente con openapi-generator-cli

Si prefieres un cliente HTTP independiente con modelos generados:

```bash
npx @openapitools/openapi-generator-cli generate \
  -i openapi.json \
  -g python \
  -o sdk/python
```

### Uso del cliente generado

```python
from openubl_client.api.invoice_api import InvoiceApi
from openubl_client.models.invoice import Invoice
from openubl_client.models.proveedor import Proveedor
from openubl_client.models.cliente import Cliente
from openubl_client.models.documento_venta_detalle import DocumentoVentaDetalle
from openubl_client.api_client import ApiClient
from openubl_client.configuration import Configuration

config = Configuration(host="http://localhost:8000")
client = ApiClient(configuration=config)
api = InvoiceApi(client)

invoice = Invoice(
    serie="F001",
    numero=1,
    proveedor=Proveedor(
        ruc="20100066603",
        razon_social="Softgreen S.A.C.",
    ),
    cliente=Cliente(
        nombre="Carlos",
        numero_documento_identidad="12121212121",
        tipo_documento_identidad="6",
    ),
    detalles=[
        DocumentoVentaDetalle(
            descripcion="Item",
            cantidad=10,
            precio=100,
        )
    ],
)

response = api.api_v1_invoice_create_post(invoice=invoice)
print(response.xml)
```

### Firma digital

El cliente generado puede firmar el XML llamando al endpoint `/api/v1/sign` con PEM o con PFX/P12.

#### Firma con PEM

```python
from openubl_client.api.sign_api import SignApi

with open("certificado.pem", "r") as f:
    cert_pem = f.read()

with open("llave_privada.pem", "r") as f:
    key_pem = f.read()

sign_api = SignApi(client)
sign_response = sign_api.api_v1_sign_post(body={
    "xml": response.xml,
    "cert_pem": cert_pem,
    "key_pem": key_pem,
})
print(sign_response["signed_xml"])
```

#### Firma con PFX/P12

```python
import base64
from openubl_client.api.sign_api import SignApi

with open("certificado.pfx", "rb") as f:
    pfx_base64 = base64.b64encode(f.read()).decode("ascii")

sign_api = SignApi(client)
sign_response = sign_api.api_v1_sign_post(body={
    "xml": response.xml,
    "pfx_base64": pfx_base64,
    "pfx_password": "mi_clave",
})
print(sign_response["signed_xml"])
```

::::note
Los nombres de clases y métodos del cliente generado siguen las convenciones de `openapi-generator` para Python (snake_case). Revisa `sdk/python/openubl_client/` para confirmar los identificadores exactos.
::::
