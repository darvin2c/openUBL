## Flujo de trabajo

<ol class="steps">
	<li>
		<strong>Modelar</strong> — Define el documento con modelos Pydantic (Invoice, CreditNote, DebitNote, etc.).
	</li>
	<li>
		<strong>Renderizar</strong> — Convierte el modelo a XML UBL 2.1 con `render()` o `to_xml()`.
	</li>
	<li>
		<strong>Firmar</strong> — Aplica firma digital XAdES-EPES con tu certificado PEM.
	</li>
	<li>
		<strong>Enviar</strong> — Envía el ZIP firmado a SUNAT y recibe el CDR de confirmación.
	</li>
</ol>

## Soporte multi-lenguaje

openUBL se puede usar desde múltiples lenguajes y plataformas:

- **Python** — Biblioteca nativa con modelos Pydantic
- **TypeScript / JavaScript** — SDK npm `@openubl/sdk`
- **Java** — Cliente generado con OpenAPI Generator
- **Go** — Cliente generado con OpenAPI Generator
- **C#** — Cliente generado con OpenAPI Generator
