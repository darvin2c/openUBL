---
title: Instalación
description: Instala openUBL con pip, uv o desde fuente. Configura el SDK de TypeScript.
---

## Python

### Con pip

```bash
pip install openubl
```

### Con uv

```bash
uv add openubl
```

### Desde fuente

```bash
git clone https://github.com/project-openubl/openubl.git
cd openubl
uv pip install -e .
```

## TypeScript SDK

Requiere Node.js 18 o superior.

```bash
cd sdk/typescript
npm install
npm run generate
npm run build
```

## Verificación

```python
import openubl
print(openubl.__version__)
```
