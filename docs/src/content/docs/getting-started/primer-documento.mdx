## Paso 3: Enriquecimiento automático con ContentEnricher

`ContentEnricher` calcula los campos faltantes de cada línea y los totales del documento:

- `fechaEmision` → fecha actual (si no se proporcionó)
- `valorVenta` = cantidad × precio
- `igv` = valorVenta × tasa IGV (solo para afectación gravada)
- `precioVenta` = valorVenta + igv
- `valorVentaTotal`, `igvTotal`, `importeTotal`

<CodeTabs tabs={[
  {
    id: 'python',
    label: 'Python',
    lang: 'python',
    code: `from openubl.enricher import ContentEnricher

enricher = ContentEnricher()
enricher.enrich(invoice)

assert invoice.valorVentaTotal == 100.00
assert invoice.igvTotal == 18.00
assert invoice.importeTotal == 118.00`,
  },

## Paso 5: Firma digital

SUNAT exige que el XML esté firmado digitalmente con un certificado X.509 válido. openUBL usa RSA-SHA1, digestión SHA1 y canonicalización C14N, colocando la firma dentro de `UBLExtension/ExtensionContent`.

Necesitas el certificado y la clave privada en formato PEM. Si tienes un archivo `.pfx`, conviértelo primero:

<CodeTabs tabs={[
  {
    id: 'python',
    label: 'Python',
    lang: 'python',
    code: `from openubl.signer import load_pfx, sign_ubl_xml\n\nwith open("certificado.pfx", "rb") as f:\n    key_pem, cert_pem = load_pfx(f.read(), password="mi-password")\n\nsigned_xml = sign_ubl_xml(xml, cert_pem=cert_pem, key_pem=key_pem)\nprint(signed_xml)`,
  },
  {
    id: 'typescript',
    label: 'TypeScript',
    lang: 'typescript',
    code: `import { client } from "@openubl/sdk";\n\nconst { data, error } = await client.POST("/api/v1/sign", {\n  body: {\n    xml,\n    cert_pem: certPem,\n    key_pem: keyPem,\n  },\n});\n\nif (error) {\n  throw new Error(JSON.stringify(error));\n}\n\nconsole.log(data.signed_xml);`,
  },
  {
    id: 'curl',
    label: 'cURL',
    lang: 'bash',
    code: `curl -X POST http://localhost:8000/api/v1/sign \\\n  -H "Content-Type: application/json" \\\n  -d '{\n    "xml": "<?xml version=\\"1.0\\"?><Invoice>...</Invoice>",\n    "cert_pem": "-----BEGIN CERTIFICATE-----\\nMIIC...\\n-----END CERTIFICATE-----",\n    "key_pem": "-----BEGIN PRIVATE KEY-----\\nMIIE...\\n-----END PRIVATE KEY-----"\n  }'`,
  },
]} />

:::note
En producción utiliza un certificado emitido por una autoridad certificadora reconocida por SUNAT.
:::

## Paso 6: Validación explícita con SunatValidator

Antes de enviar el documento a SUNAT, valida que cumpla las reglas de negocio documentadas:

<CodeTabs tabs={[
  {
    id: 'python',
    label: 'Python',
    lang: 'python',
    code: `from openubl.validator import SunatValidator\n\nvalidator = SunatValidator()\nerrors = validator.validate_invoice(xml)\n\nassert len(errors) == 0, f"Errores de validación: {errors}"`,
  },
  {
    id: 'typescript',
    label: 'TypeScript',
    lang: 'typescript',
    code: `import { client } from "@openubl/sdk";\n\nconst { data, error } = await client.POST("/api/v1/invoice/create", {\n  params: {\n    query: { validate: true },\n  },\n  body: invoice,\n});\n\nif (error) {\n  // La API devuelve 422 cuando el XML no cumple las reglas SUNAT.\n  throw new Error(JSON.stringify(error));\n}\n\nconsole.log("Factura válida");\nconsole.log(data.xml);`,
  },
  {
    id: 'curl',
    label: 'cURL',
    lang: 'bash',
    code: `curl -X POST "http://localhost:8000/api/v1/invoice/create?validate=true" \\\n  -H "Content-Type: application/json" \\\n  -d @invoice.json`,
  },
]} />

Si la lista de errores está vacía, el documento superó las validaciones de SUNAT y puede enviarse a través de los servicios web de la entidad.

## Conclusión

Con estos seis pasos has creado, enriquecido, renderizado, firmado y validado una factura electrónica UBL 2.1 lista para SUNAT:

1. **Importar** los modelos.
2. **Crear** la factura con datos de negocio.
3. **Enriquecer** automáticamente totales e impuestos.
4. **Renderizar** a XML UBL 2.1.
5. **Firmar** digitalmente el XML.
6. **Validar** contra las reglas de SUNAT.

El siguiente paso es empaquetar el XML en un ZIP con la convención de nombres de SUNAT y enviarlo a la plataforma de facturación electrónica.
